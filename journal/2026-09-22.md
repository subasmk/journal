## Self-Check

1. **What is the difference between a list and a tuple?**
   - List is mutable (can change), tuple is immutable (cannot change after creation).

2. **How do you create a function in Python?**
   - Using `def function_name(parameters):` then indent the body.

3. **What does `range(5)` produce?**
   - Numbers 0, 1, 2, 3, 4.

4. **How do you check the type of a variable?**
   - Using `type(variable_name)`.

5. **What is a dictionary?**
   - A collection of key-value pairs, accessed by key.

## My Answers

1. List mutable, tuple immutable.
2. `def name(params): body`
3. 0 to 4
4. `type(var)`
5. Key-value pairs collection
