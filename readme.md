# 📓 Subash's Daily Journal

This repo holds daily activity logs, learnings, and plans. Each day gets its own markdown file in the `journal/` folder.

## How It Works

1. Subash sends me his daily activities (text, whatever format)
2. I format it into a journal entry and push to GitHub
3. Each entry is dated and stored permanently

## Template

Each entry follows this structure:
- **Activities** — what was done
- **Learnings** — what was picked up
- **Next Day Plan** — what's coming next
